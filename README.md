# Happy New Year 2026 - 3D Drawing Animation

A premium New Year greeting website featuring:
- **GSAP 3D Animations**: Stunning perspective transforms and entrance effects.
- **Pencil Sketch Drawing**: A realistic drawing simulation that reveals a color photo.
- **Vibrant Crackers**: Dynamic fireworks background that preserves visual depth.
- **Glassmorphic Design**: Modern, premium UI with 3D mouse-tilt responsiveness.

## Technologies Used
- HTML5 / CSS3 (Vanilla)
- JavaScript
- GSAP (GreenSock Animation Platform)
- Canvas API (for fireworks)
